# Pasta do seu projeto

Coloque aqui os arquivos da sua página:

- **A copy** da página de vendas (Word `.docx` ou PDF). Se tiver upsell, o documento do upsell também.
- (Opcional) uma pasta **Identidade Visual** com logo, cores, fontes e fotos.

Como enviar pelo celular: nesta pasta, toque em **Add file → Upload files**, escolha os arquivos e toque em **Commit changes**.

Nada desta pasta vai para o site publicado.
